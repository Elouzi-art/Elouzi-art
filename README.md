## Legit-Lab

<div align="center">

### [Legit-Lab: fast URL and PDF security analysis](https://github.com/Elouzi-art/legit-lab)

[![Docker Hub](https://img.shields.io/badge/Docker%20Hub-elouzi09%2Flegit--lab-ff2e2e?style=for-the-badge&logo=docker&logoColor=white&labelColor=0a0a0a)](https://hub.docker.com/r/elouzi09/legit-lab)
![Docker Pulls](https://img.shields.io/docker/pulls/elouzi09/legit-lab?style=for-the-badge&logo=docker&color=c41e1e&labelColor=0a0a0a)
![Image Size](https://img.shields.io/docker/image-size/elouzi09/legit-lab/latest?style=for-the-badge&logo=docker&color=8f1111&labelColor=0a0a0a)
![Python](https://img.shields.io/badge/Python-5c0a0a?style=for-the-badge&logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-5c0a0a?style=for-the-badge&logo=flask&logoColor=white)

</div>

An open-source triage tool that analyzes suspicious URLs and PDF documents through several independent detection layers.

| Layer | What it does |
|---|---|
| Static heuristics | Typosquatting, raw IPs, unusual TLDs, homographs, embedded JavaScript and automatic actions in PDFs |
| Threat intelligence | VirusTotal, URLhaus and Google Safe Browsing (optional) |
| Machine learning | Experimental phishing risk score for URLs, using logistic regression |
| AI summaries | Gemini or DeepSeek, with a template-based report when no key is set |
| Languages | English, French, Arabic |

```bash
docker pull elouzi09/legit-lab:latest
docker run --rm -p 5000:5000 elouzi09/legit-lab:latest
```

Then open [http://localhost:5000](http://localhost:5000). No API key is needed for the base analysis.
