### Legit-Lab

<div align="center">

[![Docker Hub](https://img.shields.io/badge/Docker%20Hub-elouzi09%2Flegit--lab-2496ED?style=for-the-badge&logo=docker&logoColor=white)](https://hub.docker.com/r/elouzi09/legit-lab)
![Docker Pulls](https://img.shields.io/docker/pulls/elouzi09/legit-lab?style=for-the-badge&logo=docker&color=2496ED)
![Image Size](https://img.shields.io/docker/image-size/elouzi09/legit-lab/latest?style=for-the-badge&logo=docker&color=2496ED)

</div>

| Layer | What it does |
|---|---|
| Static heuristics | Typosquatting, raw IPs, unusual TLDs, homographs, embedded JavaScript and automatic actions in PDFs |
| Threat intelligence | VirusTotal, URLhaus and Google Safe Browsing (optional) |
| Machine learning | Experimental phishing risk score for URLs (logistic regression) |
| AI summaries | Gemini or DeepSeek, with a template-based report when no key is set |
| Languages | English, French, Arabic |

```bash
docker pull elouzi09/legit-lab:latest
docker run --rm -p 5000:5000 elouzi09/legit-lab:latest
```

Then open <http://localhost:5000>. No API key is needed for the base analysis.
